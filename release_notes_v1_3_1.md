### Sotto v1.3.1 Release

#### What's New

- **Voice Selection Bugfixes**: 
  - Fixed an issue where explicit English male voices would sound distorted and robotic by normalizing their pitch settings.
  - Corrected the gender mapping for Indonesian network voices to ensure Male and Female voice selections are applied accurately.
- **UI State Fixes**:
  - Fixed an issue where changing the App Language would abruptly close the Voice Settings dialog and exit Edit Mode.

#### Release Assets

- `app-release.apk`: Signed release APK directly installable on Android devices.
