### Sotto v1.3.3 Release

#### What's New

- **Bugfix**: Fixed an issue in v1.3.2 where the app would incorrectly force the system's default language for all playback, ignoring the specific language assigned to individual phrases. Phrases will now correctly play using their assigned language.

#### Release Assets

- `app-release.apk`: Signed release APK directly installable on Android devices.
